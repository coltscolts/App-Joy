# Catálogo mundial de ciudades

Las sugerencias de destinos usan `all-the-cities` 3.1.0, una instantánea local de más de 135,000 ciudades con al menos 1,000 habitantes.

El paquete está derivado del conjunto `cities-with-1000`, que a su vez proviene de los datos de [GeoNames](https://www.geonames.org/) (licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)). La integración conserva el nombre de ciudad, el país, la variante alternativa disponible y la población únicamente para ordenar resultados. No se exponen coordenadas ni se realiza una búsqueda geográfica externa.

El paquete `all-the-cities` se distribuye bajo licencia MIT. Consultar su repositorio para los términos completos: <https://github.com/zeke/all-the-cities>.
